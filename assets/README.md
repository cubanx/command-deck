# Command Deck icon

`icon.svg` adapts OpenMoji's “control knobs” (U+1F39B) by Sina Schulz.

- Source: https://openmoji.org/library/emoji-1F39B/
- Original license: CC BY-SA 4.0
- Changes: slate/cyan recoloring, full-bleed background, and application-icon sizing
- Adaptation license: CC BY-SA 4.0, https://creativecommons.org/licenses/by-sa/4.0/

The PNG files in this directory are generated Night Deck renderings of `icon.svg` and carry the same license. `icon-adaptive.svg` uses Signal in light mode and Night Deck in dark mode for browser and in-app contexts that support color-scheme media queries.
